### 🔍 Casos Práticos de Troubleshooting & Diagnóstico

> 💡 *A capacidade de investigar e resolver incidentes na prática é um dos maiores diferenciais em operações e sustentação de nuvem.*

* 🛠️ **Diagnóstico de Serviço Web Parado:** Investigação de servidor web que não respondia requisições HTTP na porta 80. Análise dos logs em `/var/log/cloud-init-output.log` e status do daemon com `systemctl status httpd`, corrigindo a inicialização do Apache.
* 🛡️ **Bloqueio de Firewall por Security Groups:** Resolução de falha de conexão e timeout de rede através da auditoria de regras Inbound do Security Group da VPC, migrando a administração para o **AWS SSM Session Manager**.
* ⚙️ **Incompatibilidade de AMIs entre Regiões:** Resolução de erro `InvalidAMIID.NotFound` em scripts de automação da AWS CLI, tornando a busca de AMIs dinâmica através do **AWS Systems Manager Parameter Store**.
